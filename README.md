# Daily Dry

Premium dry fruits & nuts e-commerce website built with React.

## Features

- Product catalog with category filtering and search
- Shopping cart with quantity controls (persisted in localStorage)
- Wishlist / watchlist (persisted in localStorage)
- Product detail pages with related products
- Bulk orders and contact forms
- Responsive design matching the Daily Dry brand theme

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Build

```bash
npm run build
npm run preview
```

## Tech Stack

- React 19 + TypeScript
- Vite
- React Router
- Lucide React icons
